# 점프 대소동!

초등 6학년 영어 수업용 플랫폼 파티 게임이에요. 영어 문제를 풀어 조각(발판·함정)을 얻고, 코스에 하나씩 놓은 뒤, 같은 맵 친구들과 동시에 달려 깃발까지 가요.

## 실행

```
npm install
npm start
```

- 학생: `http://(주소):3000/`
- 선생님: `http://(주소):3000/teacher` · 비밀번호 `finel9932!` (환경변수 `TEACHER_PASSWORD`로 바꿀 수 있어요)
- 인터넷에 올릴 때는 GitHub에 올린 뒤 Render에서 Web Service로 연결하면 돼요(`render.yaml` 포함).

## 한 판의 흐름 (3라운드, 약 5분)

| 단계 | 시간 | 하는 일 |
|---|---|---|
| 새 배정·코스 미리보기 | 6초 | 맵과 함께 뛸 친구가 바뀌어요 |
| 영어 퀴즈 | 약 27초 | 1번 낱말→그림(6초) · 2번 문장 뜻(7초) · 3번 대화 응답(9초) |
| 조각 설치 | 24초 | 한 사람이 **두 개씩** 놓아요. 정답 3개 → 후보 4개, 2개 → 후보 3개, 0~1개 → 2개 자동 지급 |
| 경기 | 3초 카운트 + 30초 | 같은 맵 친구들과 동시에 출발 |
| 라운드 결과 | 9초 | 완주 순서와 점수 |

- 조각은 라운드가 바뀌어도 맵에 남아요. 다음 라운드에 온 친구들이 그 위에 또 놓아요.
- 학생은 한 게임에서 같은 맵에 두 번 가지 않고, 직전 라운드 팀원과 다시 만나는 일도 줄여요.
- 맵 수는 인원에 맞춰 자동이에요(5명 안팎씩, 최대 6개 = 30명).
- 점수: 영어 정답 1 · 완주 3 · 첫 완주 +2 · 동전 1 · 내 함정에 친구가 걸리면 1(라운드마다 최대 3)

## 화면과 그래픽

- 첫 화면(JUMP JAM!)에서 **게임 입장 · 게임 방법 · 선생님 모드**를 골라요. 학생 입장 화면을 바로 열려면 주소 뒤에 `/#join`을 붙여요.
- 화면 틀은 원본 UI(`public/paper-ui.css`, `public/ui/`의 로고·버튼·옥상 그림)를 쓰고, 동물은 `public/animals/`, 추가 맵의 발판·장애물은 `public/kits/`를 써요. 나머지 맵과 조각은 `public/render.js`가 종이 콜라주 느낌으로 그려요.
- 글꼴(Noto Sans KR 굵은 글씨, Jua)은 `public/fonts`에 들어 있어요.

## 깜짝 이벤트 · 동전 · 역전 방패

- **깜짝 이벤트**: 마지막 라운드에 셋 중 하나가 무작위로 걸려요. 점수 두 배 / 둥실둥실(몸이 가벼워짐) / 동전 비(동전 두 배).
- **동전**: 경기마다 맵에 동전 4개가 떠요. 발판 사이 틈 위(위험한 길)에 먼저 놓여요. 주우면 1점이고, 학생마다 따로 주워요(친구가 주워도 내 동전은 남아요).
- **역전 방패**: 맵마다 그 라운드에 완주하지 못한 친구 중 점수가 가장 낮은 한 명이 다음 라운드에 방패를 받아요. 함정을 한 번 막아 주고(떨어지는 것은 못 막아요), 막힌 함정의 주인은 점수를 못 받아요.

## 부활 찬스와 지우개

- **부활 찬스**: 경기 중 떨어지거나 함정에 걸리면 영어 문제가 하나 떠요(7초). 맞히면 마지막으로 서 있던 발판에서 다시 뛰고, 틀리면 출발점으로 가요. 라운드마다 한 번만 나와요. 점수에는 들어가지 않아요.
- **지우개**: 맵에 조각이 하나라도 있으면 모든 학생의 후보에 지우개가 들어가요. 고르면 맵의 조각 하나를 눌러 지워요(내가 놓는 두 개 중 하나로 쳐요).

## 입장 코드

- 선생님이 [수업 열기]에서 반·단원·맵 세트를 고르면 **학생 입장 코드**(예: JAM428)가 정해져요. [새 코드]로 바꾸거나 직접 써도 돼요.
- 학생은 첫 화면 → 게임 입장에서 코드·번호·이름을 쓰고 동물을 골라 들어와요. 대기실의 QR을 찍으면 코드가 미리 채워져요.

## 캐릭터와 맵 배정

- 캐릭터는 한 반에서 한 명만 고를 수 있어요. 다른 친구가 고른 동물은 입장 화면에서 자물쇠와 '선택됨'으로 잠겨요. 동물이 34종이라 34명까지 겹치지 않아요.
- 맵 세트는 선생님이 골라요: 기본 맵 / 새 맵 / 추가 맵(새 맵 3종 + 정글 다리·눈꽃 산장·사탕 공장).
- 라운드마다 세트 안에서 **덜 쓴 맵부터 무작위로** 골라 배정해요. 학생은 한 게임에서 같은 맵에 다시 가지 않고, 다음 게임은 지난 게임에 쓰지 않은 맵부터 써요. 인원이 적어 맵이 1~2개만 필요해도 라운드마다 다른 맵이 나와요.
- 추가 맵에는 움직이는 장애물이 있어요: 구르는 밧줄·파도(항구), 구르는 달 돌·소용돌이(우주 정거장), 구르는 항아리·회오리(사막 시장, 회오리는 위로 날려 보내요).
